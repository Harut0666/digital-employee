# 场景 B · 技术文献研判员工 · 数据说明

## 1. 背景

某科技成果转化服务机构的技术经理，经常需要针对一个技术方向快速出一份研判简报：这个方向有哪些技术路线、谁在做、进展到什么程度、有没有值得跟进的转化线索。
业务方会给出一个技术方向和一份专利清单（只有编号、标题等基本信息），数字员工需要到专利库、论文库中查找详细信息，完成归类、比较和研判。

**本数据包全部为模拟数据**：专利编号、申请人、技术指标、论文均为虚构生成，与任何真实专利、企业、机构无关，不能作为真实技术判断的依据。仅限本赛事使用。

| 文件 | 内容 |

## 3. 字段说明

### 3.1 专利库

| 字段 | 说明 |
|---|---|
| 专利编号 | 虚构编号，格式 `ZZ{申请年份}{6 位序号}{类型码}`。类型码 A 为申请公开，B 为授权公告，U 为实用新型 |
| 标题 | 专利名称 |
| 申请人 | 脱敏后的申请人编码，如“申请人E01”；联合申请时用“; ”分隔 |
| 申请人类型 | 企业 / 高校 / 科研院所，与申请人一一对应 |
| 专利类型 | 发明 / 实用新型 |
| 申请日、公开日 | YYYY-MM-DD |
| 法律状态 | 有效 / 实质审查中 / 公开 / 驳回 / 视为撤回 / 失效（未缴年费） |
| IPC主分类 | 国际专利分类号 |
| 摘要 | 专利摘要，个别记录可能缺失 |
| 主权项 | 权利要求第 1 项 |
| 被引次数 | 被其他专利引用的次数 |
| 同族编号、同族数量 | 同族编号相同的专利属于同一项发明在不同申请中的体现 |
| 转让许可记录 | 专利权转让或许可情况，无则为空 |

### 3.2 论文库

论文编号、标题、作者单位（与专利库使用同一套脱敏编码）、期刊（脱敏后的期刊代号及类别）、年份、摘要、关键词、被引次数。

### 3.3 输入清单（CSV，UTF-8 带 BOM）

序号、专利编号、标题、申请人、申请日。

申请人编码的含义（如“E01 动力电池头部企业”）见 xlsx 中的“申请人说明”工作表。

## 4. 使用时请注意

1. 业务方给的清单是人工整理的，可能有重复行、编号错误、混入与方向不相关的专利，需要核对后再分析。
2. 发明专利一般在申请日起 18 个月公开（申请人可请求提前公开），所以最近一两年的申请量统计并不完整，做趋势判断时需要说明。
3. 同族专利应视为同一项发明，不应重复计数。
4. 个别专利的摘要缺失，可以依据标题和主权项判断，但需注明。
5. 简报中引用的每一条资料都必须真实存在于专利库或论文库中。
